# Loan-Analytics-Power-BI
Built an interactive Power BI dashboard on a bank loan portfolio, designing DAX measures for KPIs (funded amount, repayment, interest rate, DTI) and a good-vs-bad loan risk classification, with drill-down views by state, grade, term, and purpose across 2 report pages.
Bank Loan Analytics Dashboard — Power BI

Built a 2-page interactive Power BI dashboard analyzing a bank lending portfolio (loan applications, funding, and repayment performance) from a single financial_loan fact table.

Data model: Designed DAX measures for portfolio KPIs — Total Loan Applications, Total Funded Amount, Total Amount Received, Average Interest Rate, Average DTI Ratio, and a Good Loan % / Bad Loan % risk split derived from a calculated Good_vs_Bad_Loan classification (based on loan status).
Summary page: KPI cards (applications, funded amount, amount received), Good vs. Bad loan donut breakdowns, and good/bad loan % indicators for at-a-glance portfolio health.
Overview page: Trend analysis of loan issuance by month (line chart), and breakdowns by loan grade, term, purpose, home ownership, and state (clustered bar/column charts, treemap, and a geographic Azure Map), with interactive slicers and page navigation buttons for drill-down.
Applied a custom Fluent-based theme, branded KPI icons, and background imagery for a polished, presentation-ready UI.
